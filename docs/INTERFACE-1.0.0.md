# 界面规范 · 1.0.0

- 简洁清爽，浅色白底、深色低反差背景。无大卡片、米黄绿色主题、装饰性大标题、字数统计或练习模块。
- 顶部窄品牌栏：`hyggeZ　雅思学习·范文分析`；右上圆形太阳/月亮切换，只有主题按钮为圆形。
- 文章按钮横排，当前文章完整标题，其余压缩宽度并支持横向滚动。不显示横向滚动条；点击接近右侧的文章后向后滑动一段。最右侧下箭头展开完整文章列表，可直接选篇。
- 题目位于三栏整体上方；题目与其下工具横栏一起固定。横栏左侧“词汇”、中栏右侧“显示译文”、右侧“全部／结构／句型／衔接／积累”。滚动时横栏不消失。
- 三栏宽度顺序：中间最大、右侧其次、左侧最窄。正文保持全文，段落按共享网格行排列，三栏一起滚动，不做独立滚动面板。
- 段高取当前可见内容所需高度，不为空白预留固定高度。隐藏词汇不占空间，展开后按需撑开。
- 左栏词汇默认不显示，原文标记仍存在，点击展开，再点收起。右栏解释直接可见，可筛选。
- 所有译文通过按钮同时切换，默认隐藏。
- 选中文字后立即在选区末尾插入白色／深色主题输入框，不使用模态窗口；仅选标签和输入自由笔记，保存、取消。存在未保存内容时，不直接销毁输入框。
- 自定义笔记以选中文字为加粗标题，下面仅展示用户内容，保留类别和删除；不要“我的笔记”标题，不重复一行小字原文。
- 每篇存储键为 `ielts-essay-NN-personal-notes-v1`，保持第一篇旧键兼容；不把私人笔记提交 Git。导入校验原文偏移，去重合并；不自动跨设备同步。
- 更新版本需同步 VERSION、页脚和更新记录。新增文章按内容规范处理，不随意改动已确认界面。
- 顶栏增加“导出 PDF”和“文本导入”；导入框为页面内展开区域，默认收起。纯文本导入文章保存在浏览器，原有 25 篇不被覆盖；未提供译文时按钮保留但禁用，不生成空分析。
- PDF 使用独立白底单栏分页，包含当前文章全文、已有译文、全部分析与已保存的个人笔记，不依赖当前筛选和展开状态。打印完成或取消后，阅读状态保持。
- 笔记备份 JSON 可选携带 `customEssays`；导入备份时一并恢复文章和对应笔记。旧备份兼容，私人导入文本不写入仓库。
- 已导入文章再次粘贴相同题目和正文时，可补充或更新译文，保留篇目 id 和个人笔记；导入旧备份只填充缺失译文，不覆盖已有译文。
