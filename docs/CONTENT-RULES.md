# 内容规范 · 1.0.0

后续添加文章必须复用现有格式，不另做封面、仪表盘、学习任务或练习。

## 原文与译文

1. 完整保留题目和全文，不删减句子。正文分段依据来源版式；允许合并 PDF 换行、修复明显词间粘连和行末断词。
2. 不把语法、逻辑或事实修改悄悄写回正文。保留原句，在对应分析指出问题。
3. 每段提供完整中文译文，数量和顺序严格一一对应；译文不代替摘要。题目同样需要译文。
4. 若题干本身严重损坏，最小修复并在题型分析注明；原始提取文本保存在 `content/source-pages.json`。第 11、20 篇已注明此类处理。
5. 第一篇既有笔记通过文字偏移锚定，禁止无必要更改原文字符、段序或 id。

## 分类

- **词汇（左栏）**：有阅读障碍的词、较难词与熟词生义；给出词性和本文含义，必要时解释搭配。简单词不机械罗列。没有权威大纲核验，不宣称某词必属某级考试大纲。
- **结构（右栏）**：题型、任务要求、作者立场；每段讲什么、有几个论点、解释和例子如何连接；指出跑题、概念偷换、范围过大或结论新增内容。
- **句型（右栏）**：具体原句的主干、从句、非谓语或固定构式；说明成分及本句用途。只分析文章，不附迁移练习或额外仿写。
- **衔接（右栏）**：句内、句间的时间、范围、原因、结果、让步、对照、目的等关系。包括介词、介词短语、连词和过渡句；among 是介词，不能因归入衔接就称为连词。
- **积累（右栏）**：好的动词、名词、形容词、能力品质表达及同义替换；解释搭配和替换范围。同话题词汇链不必然是同义词。

## 标记与质量

- `readerNotes` 每项含 `p`（从 0 开始的段落）、`c`（vocab/syntax/link/expression）、`q`（原文精确连续片段）、`t`（简短标题）、`e`（本篇解释）。结构在 `structure` 中。
- 各类使用稳定配色，重叠区段可以对应多条批注，点击能同时定位；不得破坏原文或改变句序。
- 不用机械模板填充所有文章。每篇五类都覆盖，结构逐段分析；重点句、连接方式和语料必须来自该篇。
- 难度判断只能作为学习筛选，不能假定用户必定不认识。
- 第一篇为讲解深度基准，后续不得退化为只摘几句。逐段检查：重要难词和熟词生义、主要句子主干及从句、非谓语逻辑主语、句内和句间衔接、可积累搭配与替换限制。简单句可简讲，但不得遗漏整段。数量随语言难度变化，不机械凑数。
- 详细补充批注维护在 `content/close-reading-*.txt`，由 `scripts/enrich.py` 验证精确原文锚点并按段落与原文顺序合并。运行 `scripts/author.py` 会同时重建基础内容和这些精读批注。
- 涉及未经来源支持的研究、人物或统计，应说明未核实，不包装成事实论据。已核实的实质纠错附依据。
- 第 18 篇原文把核能列为可再生能源。EIA 将核能列为非可再生能源：[Sources of energy](https://www.eia.gov/energyexplained/what-is-energy/sources-of-energy.php)。译文忠实保留，结构批注明确纠正。

## 新文章验收

稳定 id 不复用；题干译文齐全；全文和译文等段数；逐段结构等段数；所有批注精确匹配；无未完成占位；所有筛选模式全文可还原；在两种主题和窄屏检查可读性；已有笔记可继续读取；运行项目验证和 DOM 交互测试。
