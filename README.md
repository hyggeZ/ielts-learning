# hyggeZ 雅思学习·范文分析

版本：**1.0.0**。25 篇范文，来自用户提供的《2026年10月大作文机经预测带范文》PDF 第 2–26 页。

网站：https://hyggez.github.io/ielts-learning/

打开 `index.html` 即可离线使用；同一个文件可直接由 GitHub Pages 托管。站点运行时不需要第三方库或服务。

## 使用

- 顶部文章按钮切换篇目，当前篇展开标题，其他篇缩小，横向滚动可查看其余篇。
- 顶部太阳／月亮切换明暗模式。
- 题目和“词汇／显示译文／分析筛选”横栏固定，正文三栏共同滚动。
- 左栏词汇默认隐藏，点击原文标记展开；右栏按结构、句型、衔接、积累筛选。
- 在**同一段原文内**选中文字，出现内嵌笔记框；标签必选，内容自由输入。笔记按篇目和标签归档。
- 笔记及主题保存在浏览器 localStorage。不同设备不会自动同步。右上角导出／导入 JSON，导入会去重合并。
- 从旧本地网页转到网站时，请先在已更新的本地网页导出笔记，再到网站导入。网页路径或浏览器改变可能导致本地存储隔离，原路径文件不要删除。
- 窄屏保留三栏，可横向滚动；横屏阅读更方便。
- “导出 PDF”打开浏览器打印界面，选择“另存为 PDF”。导出当前篇的全文、已有译文、全部分析和已保存的个人笔记；采用白底单栏分页，不受网页筛选或词汇展开状态影响。
- “文本导入”可粘贴题目和正文，或读取 UTF-8 `.txt`。题目放第一段，空行后为正文；也支持 `[题目]`、`[原文]` 及可选译文标记，格式见 [文本导入说明](docs/TEXT-IMPORT.md)。导入仅添加已有文字，译文和分析需另行补充；可以继续选词记笔记。
- 导入文章保存在当前浏览器，导出笔记的 JSON 会同时携带这些文章，导入备份即可在其他设备恢复。旧笔记备份仍兼容。

## 更新文章

内容规范见 [docs/CONTENT-RULES.md](docs/CONTENT-RULES.md)，界面规范见 [docs/INTERFACE-1.0.0.md](docs/INTERFACE-1.0.0.md)。

最终数据在 `content/essays.json`；每篇须有稳定 id、题干和译文、全文和逐段译文、题型和立场、逐段结构、四种锚定原文的批注。通用界面由 `index.template.html`、`style.css` 和 `app.js` 维护。

```sh
python scripts/build.py
python scripts/validate.py
npm test
```

初始内容的可复现编辑源为 `scripts/author.py`、`author_b.py`、`author_c.py`、`content/close-reading-*.txt` 及第一篇数据。改这些源后运行 `python scripts/author.py` 再构建。不要同时改生成数据和编辑源，避免相互覆盖。

## 发布

GitHub Pages 使用 `main` 分支根目录，`.nojekyll` 禁用 Jekyll。提交发布的 `index.html` 即可更新。首次发布标记为 `v1.0.0`。发布前先完成验证，再使用普通快进推送；不强制改写远端历史。

范文保留原作者措辞，译文与批注是学习整理，不代表范文获官方评分。文件名中的“预测”仅保留资料出处，不用于判断考题命中。原始 PDF、微信路径、私人笔记和认证信息不上传仓库。
